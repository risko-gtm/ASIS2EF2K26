Catálogo de vendedores

Este mantenimiento administra los registros de tbl_vendedor mediante el componente Navegador.

Campos

  • pk_idVendedor: identificador único del vendedor.
  • nombreVendedor: nombre completo, máximo 50 caracteres.
  • direccionVendedor: dirección, máximo 30 caracteres.
  • telefonoVendedor: teléfono, máximo 20 caracteres.
  • estadoVendedor: use 1 para activo y 0 para inactivo.

Operación

  1. Pulse Ingresar, complete los datos y pulse Guardar.
  2. Para cambiar un registro, selecciónelo, pulse Modificar y guarde.
  3. Para eliminarlo, selecciónelo y pulse Eliminar.
  4. Use Imprimir para obtener el reporte de vendedores.

Las operaciones realizadas se registran automáticamente en la bitácora de Seguridad con el usuario autenticado.
